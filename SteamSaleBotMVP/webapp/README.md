# SteamSale Mini App — полная версия (демо)

Эта папка входит в общий проект `SteamSaleBotMVP`. Telegram-бот и worker
запускаются из корня проекта и используют PostgreSQL, а выгруженная из Arena
Mini App пока использует отдельное демо-состояние в `webapp/data/demo_state.json`.
Кнопка `/app` в боте появится после настройки `WEBAPP_URL` в общем `.env`.

Мини-аппка для Telegram-бота SteamSale. **Вся функциональность бота пересобрана
в интерфейс** и работает на живых данных Steam (без `STEAM_API_KEY`).
Демо-режим: данные хранятся в `webapp/data/demo_state.json`, вместо пользователя —
демо-профиль с активным Premium (его можно отозвать и посмотреть free-гейты).

## Запуск

```bash
cd webapp
python3 server.py        # http://0.0.0.0:8787
```

## Что внутри (экраны)

| Экран | Функции бота | Данные |
|---|---|---|
| 🎮 **Мои игры** | `/watcher`, `/list`, `/delete` + целевая цена | поиск + карточки с живой ценой, «горячая» полоска |
| 🔥 **Сделки** | дайджест `/digest`, сезонный баннер | ваши скидки сейчас + **глобальный фид скидок Steam** (featuredcategories) |
| 📈 **Рынок** | `/track_item`, `/market_list`, `/market_delete` | реальные цены Steam Community Market; **автокомплит с иконками** при вводе; витрина предмета (иконка, тип, цена/объём, **мини-график цены**); иконки в карточках алертов; одноразовые алерты ниже/выше |
| 🔔 **Лента** | уведомления воркера (`worker.py`) | события: скидка, исторический минимум, цель, market, дайджест; бейдж непрочитанных |
| 👤 **Профиль** | `/premium`, `/trial`, `/threshold`, `/region`, `/digest`, `/referral`, `/import_wishlist` | премиум/триал/порог/регион/дайджест/вишлист/статистика экономии |

Дополнительно в карточке игры: **история цены с графиком** (аналог `/history`),
установка **целевой цены**, ссылка на Steam.

## Архитектура

```
webapp/
  server.py        aiohttp: /api/* + статика + фоновый воркер (полный цикл раз в 150 с)
  steamapi.py      клиент публичного Steam API (appdetails, storesearch, specials, Market, wishlist)
  store.py         DemoStore: состояние + логика уведомлений (как notifier/repository бота)
  static/          фронтенд: index.html, style.css, app.js (ванильный JS, без CDN и сборки)
  data/            demo_state.json (создаётся автоматически; игнорируй в git)
```

Воркер (внутри server.py) повторяет логику `worker.py` бота: опрашивает цены,
пишет «снэпшоты» в историю, шлёт события с дедупликацией по уровню скидки,
отмечает исторический минимум (Premium), проверяет target-цены и одноразовые
market-алерты, собирает дайджест + сезонный баннер (не чаще раза в 6ч / неделю).

## Честные оговорки демо

- **История цен стартовых игр** — сгенерирована по типовым сезонным распродажам
  Steam (в UI стоит пометка). После этого каждая проверка дописывает **реальные**
  наблюдения цены.
- **Steam Community Market троттлит по «отпечатку» Python-клиента** (429 на
  urllib/aiohttp, но не на curl — проверено). Поэтому в демо Market ходит через
  curl-подпроцесс; в боевом боте это отдельный вопрос лимитов (см. README бота,
  раздел про Market).
- **Полная история цен Steam Market доступна только под логином** (pricehistory
  отдаёт 400/429 анониму). Поэтому мини-график предмета честный: реальные точки
  копятся при каждой проверке цены (воркером и при поиске), а для первых секунд
  демо-реконструкция помечается в UI как «(демо)». Иконки/тип/каноничные названия —
  из публичного поиска Market (настоящие).
- **Смена региона** очищает историю (она привязана к валюте) и пересчитывает цены.
- **Триал** — один раз на «чат» (как в боте: `trial_used_at`); «Продлить Premium»
  — демо-имитация оплаты Stars (+30 дней).
- **Вишлист**: `Демо-вишлист` добавляет реальный набор игр; поле `steamid64`
  пытается получить настоящий публичный вишлист (без ключа). Привязка по нику
  требует `STEAM_API_KEY` — в боте она есть.

## Обновления

- **📈 Рынок пересобран в три блока** (вкладка «Рынок»):
  1. **🗺 Обзор рынка Steam** — топ-10 предметов игры по числу активных лотов
     (CS2 / Dota 2 / TF2 / Rust; `GET /api/market/overview?game=…`). Реальные цены
     «купить сейчас» Steam Market, пересчёт в ₽ по «курсу Steam» (render отдаёт цены
     только в USD-центах; курс снимается с бенчмарк-предмета через priceoverview раз
     в 10 минут и кэшируется). В строке: иконка, имя (локализовано под регион),
     цена, число лотов и «тренд за день» (▲/▼ против точки ~24 ч назад из истории).
     Клик по предмету открывает ценовой компас и форму алерта. При отказе Steam —
     последний удачный снимок с плашкой `stale`.
  2. **🧭 Ценовой компас** — в результатах поиска предмета: вердикт
     «дёшево / норма / дорого» по позиции текущей цены внутри диапазона своей
     истории, минимум/средняя/максимум, шкала с маркером и подсказка (когда
     выгодно). Диапазон строится по `market_history` — первые точки это
     демо-реконструкция (помечено честно), дальше копятся реальные наблюдения.
  3. **📡 Живой тренд алертов** — карточки алертов опрашивают `/api/market/alerts`
     каждые ~25 с, пока открыта вкладка: цена, поменявшаяся с прошлого тика,
     подсвечивается и получает стрелку ▲/▼ с процентом; при срабатывании
     (алерт снят сервером) — жёлтый баннер «🎯 цена пересекла цель» над списком
     + тост + событие в ленте. Рядом с ценой — мини-тренд за сутки по истории.
- **Демо-история Market** стала плотнее: шаг ~23 ч с якорем «сутки назад» (раньше
  ~3,2 дня), чтобы «тренд за день» и компас имели смысл сразу; `_seed_market_series`.
- **Исправлен спам «🏆 Исторический минимум»**: событие шлётся только когда цена
  упала ниже *уже объявленного* минимума (поле `low_notified_cents` у игры), а не
  «ниже минимума истории» на каждом цикле — демо-точки кривой больше не «подпирают»
  порог бесконечно. Накопившийся в ленте спам разово вычищается при загрузке
  (остаётся самое первое срабатывание). Один регресс-тест: цена упала → выросла →
  снова упала к прошлому минимуму — уведомление не дублируется.
- **💼 Кошелёк вишлиста** (главная): «купить весь список прямо сейчас» — сумма
  полных цен vs сегодняшних из кэша реальных цен Steam; анимированные счётчики,
  стек-бар по играм, разбор со скидками (клик открывает карточку игры). Поле
  хранит только факт; новых запросов к Steam не делает (`/api/wallet`).
- **⚡ Пульс Steam** («Сделки» → «Глобально»): показывает не «52 сделки», а
  **реальное число игр со скидкой в каталоге Steam региона** (считается по первой
  странице листаемого каталога; для RU сейчас 9 519 игр без DLC/софта).
- **🗂 Весь каталог распродаж** («Сделки» → «Глобально»): внизу вкладки — **полный
  листаемый список всех игр со скидкой региона** (страницы по 100 через offset
  `start` до самого конца; `GET /api/deals/global?start=N&q=…&maxprice=…&filter=…`,
  `SteamClient.deal_page()`). Автоподгрузка по мере прокрутки (IntersectionObserver),
  «Следить» прямо из строки, дедупликация по appid. Сразу после пульса — витрина
  «🏆 Топ продаж Steam со скидкой» (подборка Steam globaltopsellers), каталог — ниже.
  **Фильтры каталога** (применяет сам Steam, не клиент — все проверены на выдаче):
  поиск по названию (`q`), цена «до 300/600/1 200 ₽» (`maxprice` — только «лесенка»
  Steam), `filter=weeklongdeals` / `filter=globaltopsellers`, сортировка по цене
  (`sort_by=Price_ASC/DESC`). Смена фильтра сбрасывает листание и считает число
  заново из первой страницы. Steam лимитирует серию страниц (429 после ~30 быстрых
  запросов): сервер держит зазор между живыми запросами и глобальный кулдаун,
  пустые страницы не кэшируются, клиент сам пережидает и продолжает.
- **Живучесть при отказе Steam**: `/api/deals` при «тихом» отказе Steam не затирает
  фид пустотой, а отдаёт последний удачный снимок с флагом `pulse.stale` (в UI —
  жёлтое предупреждение «Steam сейчас не отвечает — показан последний снимок»);
  каталог при 429 сам уходит в кулдаун и продолжает после паузы.
- **💼 Кошелёк вишлиста** считает и анимирует **в рублях/валюте, а не копейках**
  (числа `moneyNum`/`countMoney`, разделители тысяч по региону).
- **🔥 Автокарусель «Сейчас горит»** на главной под кошельком: свои игры со скидкой
  + топ глобальных сделок Steam, слайд держится 5 с, есть точки/стрелки/свайп,
  пауза при наведении; кнопка «＋ Следить» добавляет игру из слайда.
- **Спарклайны** в карточках market-алертов: `/api/market/alerts` теперь отдаёт
  хвост реальных наблюдений (`history`) — воркер дописывает точку при каждой
  проверке цены предмета, UI рисует мини-тренд (вниз/вверх/ровно).

## Масштаб и лимиты Steam (важно до продакшена)

- Steam лимитирует **быстрые серии** поисковых страниц (~30 запросов подряд) по IP —
  это ограничение сервера-агрегатора, а не пользователей. Все пользователи делят
  один общий пул: каталог кэшируется на уровне `(регион, start, фильтр)` в памяти,
  листание сериализовано глобальным локом + зазор `_CATALOG_GAP` и кулдаун после 429.
  То есть при 1000 листающих каталог одновременно Steam получит те же ~1 запрос/1.2с,
  что и при одном: разница лишь в скорости появления новых страниц для отдельных
  пользователей (они ждут своей очереди; кэш 5 мин снимает повторные обращения).
- В реальном деплое: общий кэш каталога выносить в Redis/единый «fetch-воркер»,
  чтобы страницы фетчил один процесс/сервис, а инстансы отдавали из кэша.
- **Цены игр по пользователям дедуплицировать по appid**: один запрос на игру,
  сколько бы пользователей её ни отслеживало (сейчас демо-воркер и так один).
- При полном отказе Steam интерфейс деградирует мягко: фид/кошелёк показывают
  последний удачный снимок (`stale`), каталог честно сообщает «Steam притормозил»
  и продолжает после паузы; никаких «пустых» экранов и каскадных ошибок.
- **Обзор рынка делит тот же общий пул Steam Community**: на игру — один render-
  запрос за `_OVERVIEW_TTL` (75 с) плюс один priceoverview на курс раз в 10 минут;
  алерты (один priceoverview на предмет за цикл воркера 150 с) и живой тик клиента
  (25 с) читают в основном кэш цен, а не Steam. В проде — те же правила, что для
  каталога: общий кэш/очередь и дедуп предметов между пользователями.
- `market_history` ограничена: ≤250 точек на предмет и ≤140 предметов (старые
  эвакуируются), поэтому «обзорные» предметы не раздувают состояние бесконечно.

## Новое в этой серии

- **🎯 Sniper-алерты «в процентах» (Premium-фича для трейдеров)** — у алерта можно
  выбрать цель не «по цене ₽», а «% от текущей»: сервер сам берёт живую цену и
  считает цель (напр. «ещё −8% от 61 ₽ ≈ 56 ₽»), при каждой проверке пересчитывает
  её от базовой цены. Создание из формы, превью-блок **Sniper-анализ**: ползунок
  «зона входа −2…40%», оценка шанса «цена дойдёт до цели» по истории (доля точек
  ≤ цели), вердикт и кнопка «＋ Следить ниже этой цены». Premium-гейт честный:
  без Premium виден «замок» и подсказка.
- **📡 «Живая волна» обзора** — вверху обзора счётчики «▲ дорожает / ▼ дешевеет /
  ровно» по топ-10 + топ движущихся позиций за сутки; вкладка «Рынок» сама
  обновляет обзор ~раз в 45 с, пока открыта (данные Steam, тренд по истории цен;
  автотик не гоняет Steam, пока не накопится ответ).
- **🛠 Демо-админка на `/admin`** — скрытый пульт (доступ по коду `ADMIN_CODE`,
  по умолчанию `steamsale-demo-2026`; открыть `/admin?code=…` или ввести код на
  странице). Показывает: heartbeat воркера и последний цикл, статус Steam
  (Market/сделки: последний успех/пусто-429), состояние кэшей (цены Market, фид
  сделок, обзор по играм, курс ₽, каталог распродаж) и хвост логов сервера.
  Управление: выдача Premium (7/30/365/произвольное), отзыв, рассылка в ленту,
  «прогнать цикл сейчас», полный сброс демо-состояния. API под
  `/api/admin/*`, авторизация — httpOnly-cookie после логина (или
  `X-Admin-Code` для curl). В проде заменить на нормальный auth-слой.
- **Устойчивость к 429**: обзор дополнительно пишет **снимок на диск**
  (`market_overview_snapshot.json`) и при 429-окне Steam отдаёт его с плашкой
  `stale` (а не пустой экран); превью-метаданные предметов получили негативный
  кэш 5 минут, чтобы живой тик алертов не долбил Steam, пока тот молчит.

### Почему Market «молчал» (важная находка для продакшена)
Steam Community Market **стабильно отдаёт 429 на curl с флагом `--compressed`**
(заголовок Accept-Encoding с gzip/br/zstd), хотя без него тот же URL отвечает 200.
Всё время, пока обзор/алерты «сидели без ответа», сервер ходил через
`curl --compressed`; достаточно убрать флаг — и 429 исчезают. Плюс два усиления:
single-flight на живую цену (`_market_price_smart` — проверка+запрос атомарны, иначе
два параллельных тика летят в Steam залпом) и кулдаун обзора с авто-повтором и
резервной витриной на случай новых пауз Steam.
